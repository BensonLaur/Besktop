# Besktop v0.1.0 发布说明（候选稿）

Besktop 是一个安全的 Windows 桌面娱乐工具。运行后，你熟悉的桌面会变成一个全屏小剧场：图标从真实位置陆续醒来，长出白色手脚，自由闲逛，并在自然靠近时发生短暂但完整的局部交锋；退出后，真实桌面保持原样。

## 这一版有什么

- 重建当前桌面的壁纸、图标、文字和任务栏静态画面。
- 让全部有效图标按空间分散的首批、第二批和兜底批次错峰觉醒；已醒来的邻近演员可以让沉睡图标稍早加入，但不会把所有图标瞬间拉成同一波。
- 为图标长出白色两段式四肢，并在任务栏之外自由漫游、停留、使用步态 IK 行走和连续 3D 转身。
- 在第一批演员就绪并完成一段纯探索后，由个体倾向、局部感知、双向意图和安全仲裁决定是否发生相遇，不全局随机点名，也不强迫明确避让的演员参战。
- 允许多个互不冲突的局部相遇并行；每场仍只有两名演员，Combat 通常进行 3–7 次攻防交换，再带着命中、格挡、闪避或打空的结果余波分开。
- 让附近的非参与演员按距离、视野和倾向选择忽略、短暂注意、在安全区域外观察或主动避让，不设置固定的全局旁观人数。
- 支持普通文件、文件夹、快捷方式、缩略图，以及“此电脑”“回收站”等虚拟 Shell 项的真实图标。

当前版本不包含生命值、伤害数字、死亡、淘汰、胜负或三人以上围攻，也不提供设置窗口。

## 运行控制

- `P`：在“自动互动”和“仅自由漫游”之间切换。关闭后不再创建新相遇或新反应，已经开始的交锋会完成当前交换并自然收尾；再次开启后先保留一段纯漫游。该选择只对本次运行有效。
- `Esc`：正常退出 Besktop。
- `Ctrl+Shift+B`：强制安全退出，作为备用退出方式。

## 安全边界

所有演出都发生在 Besktop 自己重建的全屏舞台中。Besktop 不会移动、隐藏、删除、重命名或改写真实桌面文件，不会控制 Explorer，也不会修改真实任务栏。任务栏画面只在启动时静态捕获，不可点击，也不会持续刷新时钟或托盘状态。

本版本不自启动、不后台驻留、不提权。退出后应回到原来的真实桌面；正式发布前仍需由用户完成视觉和桌面安全验收。

## 使用方式

1. 64 位 Windows 下载 `Besktop.exe`；只有 32 位 Windows 下载 `Besktop-win32.exe`。两者是同一软件的架构兼容版本，每位用户只需选择一个。
2. 双击运行，无需安装。
3. 观看图标分波醒来、自由漫游和发生局部互动。
4. 可按 `P` 切换纯漫游，按 `Esc` 或 `Ctrl+Shift+B` 退出。

两个版本都是独立单 EXE，无需另装 VC Runtime。当前版本没有安装器和自动更新，也尚未进行代码签名。首次运行时，Windows 可能显示安全提示；请只从项目确认的官方发布页下载，并核对正式 Release 页面提供的 SHA-256。不要关闭安全软件、添加排除项或绕过其检测。

## 当前候选验证状态

当前候选以产品代码基线 `33a81a1` 生成。x64 Debug、x64 Release 与 Win32 Release 各自重新构建后，均发现并通过 10 项注册测试；两套 Pack CLI、PE 架构、版本资源、应用图标和静态运行库边界也已验证。当前 Windows 11 环境中的 x64 `Esc`、Win32 `Ctrl+Shift+B` 短启动均以退出码 0 结束，x64 普通 Release 连续运行 5 分钟期间未见崩溃、卡死或资源持续增长。

两个候选均为 `NotSigned`。Microsoft Defender 使用当时的官方引擎与定义对两个 EXE 做单文件扫描，均未发现威胁。以上只是本轮自动验证结果，不替代 SmartScreen、干净机器、不同 Windows/DPI/任务栏/显卡环境和动画观感的人工验收。详细证据见 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)。

## 支持范围与已知限制

- 当前重点是主显示器和 Windows 默认 Shell；复杂多显示器、第三方 Shell 和非主显示器任务栏尚未完整支持。
- 任务栏是启动时的静态画面，时间、托盘和按钮状态不会刷新，也不能交互。
- 不同 Windows 版本、32 位实体系统、125%/150% DPI、任务栏四向位置和自动隐藏仍需人工验证。
- 全屏程序、远程桌面、录屏软件、特殊显卡和安全软件组合可能需要额外兼容性验证。
- 当前没有安装器、自动更新和代码签名，未签名文件的 SmartScreen 首次运行提示与下载信誉仍待验证。
- 仓库尚未确定官方支持/打赏 URL；正式发布前由用户决定，不在候选稿中放置占位链接。
