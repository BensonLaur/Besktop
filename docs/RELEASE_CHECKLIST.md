## 当前默认体验

当前候选不再只是“全部图标觉醒和自由漫游”。普通 Release 默认提供：

- 空间分散的首批、第二批和兜底批次分波觉醒，以及邻近演员带来的克制扩散。
- 任务栏安全区域内的自由漫游、步态 IK 和连续 3D 转身。
- 个体倾向、局部感知、双向意图与安全仲裁驱动的局部相遇。
- 多个互不冲突的双演员相遇并行运行；每场 Combat 通常包含 3–7 次攻防交换。
- 非参与演员对附近事件的短暂注意、观察或避让。
- `P` 在本次运行内切换“自动互动”和“仅自由漫游”；`Esc` 与 `Ctrl+Shift+B` 安全退出。

当前仍不包含生命值、伤害数字、死亡、淘汰、胜负或三人以上围攻。
