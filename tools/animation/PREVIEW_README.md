# Besktop 三维动画基础预览

这是 G1–G5 的本地开发预览，不是正式发布版，不需要联网支付或安装运行库。

本轮下肢更新：双人示例使用统一中立站姿与独立落脚求解，站定时锁定脚掌位置及朝向，修正歪脚和膝盖抖动；取消时空中脚原位落下。新增 `preview/pair-feet-*.png`，记录接近、保持与退回。当前仍是水平抬脚的简化步态，尚无精修脚跟/脚尖滚动，原始单人动作不变。

本轮头颈更新：握手/拥抱从中立底姿开始，不再直接复制原 idle 的歪头；握手加入有限俯仰，拥抱在接触阶段轻微侧头，结束和取消回正。原始单人动作不变。`preview/pair-neck-*.png` 可对比开始、接触和恢复。

2026-10-18 比例溯源 v4：腿段分配依据固定版本 OpenSim 中立位框架跨度，增加来源、端点、推导公式及导出回归。实际调整约 1.26 毫米，保留已认可的肩颈和全身 v3 形体；不是国标平均人体。详见 `ANTHROPOMETRY.md`。

`preview/fullbody-0..3.png` 为全身四视图，`foot-contact-0..1.png` 为脚掌落地近景；`shoulder-*.png` 继续提供站立、行走和举手的肩颈近景。

建议顺序：

1. 看 `G1-G5-preview.mp4`，32 秒了解这次变化。
2. 打开 `AnimationLab.exe`。空格暂停，拖动视角，滚轮缩放，1/2/3/4 切视角；H 握手，U 拥抱，I 切图标，Esc 退出。
3. 阅读 `IMPLEMENTATION_REPORT.md`：已完成的工程能力、验证结果和仍未通过的观感验收。
4. 如果想试桌面场景，再手动打开 `Open-3D-Stage.cmd`。它只在自己的窗口中演出，不改真实桌面；Esc 退出，Ctrl+Shift+B 备用退出。

请注意：

- 普通行走/站立/停止/转弯使用外部动捕；庆祝、握手、拥抱是编排与约束原型，还不是精修真人双人动作。
- 新桌面场景暂时只有漫游和外观验证，没有迁入旧格斗、小螃蟹及打赏 UI。
- `Besktop.exe` 直接双击仍是旧 Icon Fight；`Open-3D-Stage.cmd` 才是三维实验舞台。
- 本轮 x64，仅在当前 Windows 11 机器验证；不保证其他显卡、DPI、多屏和系统版本。
- 无代码签名、无自动更新。不要为了运行关闭安全软件或添加排除项。
- `G1-stick-figure.blend` 需要 Blender 才能编辑；普通运行 EXE 不需要 Blender。
- `preview/` 全部为合成渲染和验证记录，不含真实桌面截图。
- `SHA256SUMS.txt` 是校验清单，不需要运行。

更多操作与动作扩展步骤见 `WORKFLOW.md`，素材及依赖许可见 `THIRD_PARTY_NOTICES.md` 和 `LICENSE`。
